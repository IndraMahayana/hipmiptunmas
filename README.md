# HIPMI PTUNMAS

Landing page React + Vite untuk HIPMI PTUNMAS, dibuat responsif dan siap dipublikasikan ke Vercel.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
npm run preview
```

## Deploy ke Vercel

Impor repository ini ke Vercel. Framework akan terdeteksi sebagai Vite; gunakan perintah build `npm run build` dan direktori output `dist`. File `vercel.json` sudah menyiapkan rewrite untuk aplikasi satu halaman.

## Sebelum dipublikasikan

Sesuaikan konten contoh di `src/App.jsx` dengan informasi resmi HIPMI PTUNMAS:

- Angka anggota, program, dan mitra pada bagian statistik.
- Nama/deskripsi program kerja dan kategori partner.
- Email sekretariat (`sekretariat@hipmiptunmas.id`) dan tautan Instagram.
- Lokasi pada peta; saat ini peta menampilkan area umum Indonesia sebagai placeholder.
